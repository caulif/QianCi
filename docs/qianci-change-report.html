一、产品规划与用户视角

  • 新增统一规划文档 docs/qianci-optimization-roadmap.md，把弱反馈透明化、页面兼容、性能、联网补查、隐私与导出整合到一个路线图。
  • 从用户角度补充多个场景：为什么词不见了、页面为什么不好用、查词失败怎么办、数据会不会外发、阅读结束如何轻复盘。
  • 明确潜词定位：不是整页翻译，也不是重型背词平台，而是安静、低打扰的英文阅读辅助扩展。

二、内容页与 Tooltip 交互

  • Tooltip 改为更完整的非模态交互卡片：支持显式关闭、外部点击关闭、Escape 关闭、键盘焦点返回。
  • “我认识”后不再直接消失，而是显示“已标为认识 / 撤销”，撤销后恢复旧 profile、生词记录和页面标注。
  • “继续提醒”后显示“会继续提醒 / 撤销”，撤销后恢复点击前的弱反馈状态。
  • 新增 profile 串行保存队列，减少快速点击和撤销时旧保存覆盖新状态的风险。
  • Tooltip 显示词条来源：本地词库、用户自定义、在线缓存；带 provider attribution 的在线词条也会保留“来源：在线缓存”。

三、页面兼容与性能

  • 内容扫描改为分片队列，避免长页面同步扫描造成主线程卡顿。
  • 支持动态 DOM、SPA 插入内容和 open shadow DOM 扫描，同时保留关闭和清理逻辑。
  • 加入页面诊断数据：扫描文本段、标注数量、扫描状态、页面风险提示。
  • 站点模式支持自动标注、仅手动查词和暂停，复杂页面可以安全降级。
  • 跳过输入框、编辑器、代码块、按钮等高风险区域，减少页面误伤。

  • tests/unit/*：补充 popup、tooltip、content、manifest、站点策略、重试队列等测试。

四、Popup 与 Options 设置页

  • Popup 增加当前页面状态卡：标注数量、扫描文本段、风险提示、重扫按钮。
  • Popup 支持站点模式切换：自动、仅手动、暂停，并在切回自动时请求重扫。
  • 增加密度快捷操作：“少标一些 / 多提醒一点 / 恢复平衡”，并支持撤销最近一次密度调整。
  • Options 增加首次使用引导：英语水平、标注密度、查词触发方式和“我认识”的解释。
  • Options 弱反馈区域显示被跳过隐藏数量、最近跳过词、恢复提醒、总是提醒和重置弱反馈。
  • 数据与隐私面板说明本地数据类型、联网边界、联网缓存、重试队列和站点设置清理入口。

五、联网查词可靠性

  • 联网查词增加错误分类：未找到、限流、服务不可用、网络异常、超时、解析异常。
  • Provider 链增强：主服务失败后尝试 dictionaryapi.dev，英文释义再用 MyMemory 翻译中文。
  • Tooltip 失败提示更具体，请求入队时显示“已加入重试队列，稍后自动重试”。
  • Options 展示联网补查重试队列详情：单词、失败原因、尝试次数、下次重试时间。
  • Service worker 侧补充 alarm / 队列处理相关测试，避免失败请求静默丢失。

六、学习回顾与导出

  • 设置页增加轻量学习回顾：最近查过、查得最多、最近认识。
  • “查得最多”的词支持一键标为认识，不必进入完整表格操作。
  • 生词导出支持 CSV、版本化 JSON，以及 Anki-friendly CSV。
  • Anki CSV 使用 #separator、#columns 和 tags 文件头，避免普通表头被 Anki 当作卡片。

七、测试与质量护栏

  1. 新增 tooltip 来源透明、关闭行为、按钮尺寸、焦点返回和撤销测试。
  2. 新增 content 扫描分片、动态 DOM、shadow DOM、站点模式、撤销和持久化竞态测试。
  3. 新增 popup 密度撤销、站点模式、页面诊断、反馈模板和空状态测试。
  4. 新增 options 弱反馈恢复、队列清空、隐私清理、导出和 onboarding 测试。
  5. 新增联网 provider fallback、错误分类、重试队列和 manifest 权限测试。
